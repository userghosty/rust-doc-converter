# Конвертер документов

Настольное приложение для локальной конвертации DOCX ↔ PDF в Linux. Написано на Rust с использованием GTK 4, [dxpdf](https://github.com/nerdy-pro/dxpdf) и [PDF Oxide](https://github.com/yfedoseev/pdf_oxide). Для конвертации не нужны LibreOffice и интернет.

Выберите документ и укажите папку и имя результата. Исходные и существующие файлы не перезаписываются.

## Сборка и запуск

Понадобятся Rust с Cargo, системная GTK 4 и инструменты компиляции, включая C/C++ и Clang. Для первоначальной загрузки зависимостей нужен интернет; сборка графического движка может занять несколько минут и несколько гигабайт дискового пространства.

```bash
cargo build --locked
./target/debug/rust-doc-converter
```

На других дистрибутивах и архитектурах работа пока не проверена. Для сборки может потребоваться пакет разработки GTK 4.

## Конвертация из Nautilus

Для пункта «Скрипты → Конвертировать DOCX ↔ PDF» понадобятся Nautilus и Zenity. После сборки выполните:

```bash
install -Dm755 target/debug/rust-doc-converter ~/.local/bin/doc-converter
install -Dm755 scripts/nautilus-convert.sh "$HOME/.local/share/nautilus/scripts/Конвертировать DOCX ↔ PDF"
```

Затем нажмите правой кнопкой на одном DOCX или PDF и выберите скрипт. Если приложение пересобрано, повторно установите его в `~/.local/bin/doc-converter`.

## Ограничения

- PDF без текстового слоя (например, сканы) не поддерживаются: распознавание текста ещё не добавлено.
- Максимальный размер входного файла — 50 МБ.
- Сложное оформление может измениться, особенно при преобразовании PDF в DOCX. Проверяйте результат.
- Доступна сборка из исходного кода; готовый исполняемый файл в репозитории не публикуется.
